# Contributing

Use Python 3.12, install `.[test]`, and run the full pytest suite. On Linux use `QT_QPA_PLATFORM=offscreen`; native platform acceptance still requires the actual platform.

Keep recovery and viewer logic shared across operating systems and source adapters. Unknown formats require structural evidence, strict bounds, synthetic fixtures and explicit uncertainty. Do not introduce filename-specific offsets, weaken validation, or replace recoverable original content with screenshots.

Submit source and synthetic fixtures only. Never commit books, recovered pages, private databases, credentials or generated forensic output. Document fixture provenance and independent expected results. Tests involving locally owned samples must remain opt-in.

Describe behavior, rationale and actual tests in pull requests. Contributions are provided under the project license; third-party material must retain its own compatible notices.
